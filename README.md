# Blue Diamond Films Ltd. Website

Multi-page website built with HTML, CSS, JavaScript, Tailwind CSS, and Vite.

## Run locally

1. Install Node.js (LTS).
2. Open this project folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL shown in the terminal.

## Production build

Run `npm run build`. The production website is generated in `dist/`.

Pages: Home, About, What We Do, Divisions, Team, Contact.
